## CodePal v1.3.0

本版本在 CodePal 的监控历史之上新增每日工作回顾，让最近的 AI 编码会话可以按日期和项目复盘，而不只是停留在实时 session 列表里。同时，本版本也加强了 session 时长、项目归属和 Analytics 筛选能力，更适合每天高频使用。

### 亮点

- **每日工作回顾**：新增个人工作回顾页，汇总最近 14 天已完成和仍在进行的 session，区分 managed / observed 来源，并支持快速跳回当前 session。
- **按项目聚合**：session、历史、工作回顾和用量分析共用项目归属逻辑，可以按仓库扫描工作，而不是只看原始 agent 流。
- **实时运行与上下文信号**：session 行展示运行时长、最近运行时长、总 session 时长，以及上游可用时的上下文压力。
- **Analytics 筛选与趋势清理**：项目 / agent / 模型筛选会持久保存；即使筛选后没有趋势点，趋势控制区也保持可见；同时移除了 Analytics 页上的临时报告脱敏开关。
- **回顾体验打磨**：项目组支持折叠，长列表保持紧凑，并过滤低价值 prompt 和工具调用样板文本，减少回顾噪音。
