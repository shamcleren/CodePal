## CodePal v1.2.0

本版本将 CodePal 从被动监控转向可操作的工作流基础设施。新增 Report Facts 和工作事项基础，用 SVG 折线趋势图替代每日柱状图，引入 Work Health 健康条带，并在会话视图顶部提供关注队列横幅。

### 亮点

- **Report Facts 与工作事项**：从会话、工作事项、操作日志和用量数据中确定性地推导日报/周报/月报 facts。工作事项跟踪 `waiting`、`needs_follow_up`、`failed`、`completed` 和 `deferred` 状态。
- **LLM 报告生成**：基于 Report Facts 的手动 LLM 报告生成，通过设置开关控制，支持模型选择，包含会话标题和模型名称脱敏。
- **关注队列横幅**：需要关注的会话（失败、等待、需跟进）在会话视图顶部高亮展示，支持展开详情和跳转。
- **SVG 折线趋势图**：用 LTTB 降采样的 SVG 折线图替代每日堆叠柱状图，支持 agent 筛选 chips 和悬停十字线提示。
- **Work Health 健康条带**：分析页紧凑的健康信号——需处理数、最长等待、未恢复失败、上下文接近满、与前一等长区间的费用异常。
- **报告设置面板**：偏好设置中的 LLM 报告开关和默认模型选择。
- **语义内置主题**：`graphite-ops`（暗色）和 `paper-ops`（亮色），分析、健康条带和趋势图组件完整适配主题。
